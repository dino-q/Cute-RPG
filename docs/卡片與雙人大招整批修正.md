# 卡片升級、雙人大招與跟身特效修正

## 升級語意

同一張卡每級文字表示目前總效果；升級只增加差額。不同卡仍各自貢獻，攻擊力／血量／機率等相加；倍率型效果相乘；同類固定範圍／狀態取較強值。攻速+80%表示每秒攻擊次數1.8倍，攻擊間隔除以1.8。時光沙Lv1/2/3分別是1.4/1.6/1.8倍，升三級不再乘0.6×0.4×0.2。

不升級的一次性卡維持其一次取得效果。原本直接設定等級的狀態卡亦沿用原等級設定。黑洞傷害等級修正為0／1／2，對齊無額外倍率／+35%／+70%；萬物吞噬近戰命中回復移除最低5HP，遵守0.5／1／2HP。疾風靴文字改為卡片大招CD，破甲箭文字明示護甲Boss每秒傷害上限，時停說明Boss免疫凍結。

## 雙人大招

P1／P2共享castPlayerUltimate；doUlt與doP2Ult只是持有者入口。各自集氣、各自冷卻，長按與攻擊連擊集氣使用相同倍率。移除P2固定3秒與AI固定8秒的特例。黑洞、時停、磁力場、閃電步按持有者卡片執行，兩份區域效果可同時存在。HOST結算，CLIENT傳按住狀態與單次發動，接收自己的集氣／冷卻／效果剩餘時間；HUD不再顯示P1集氣。重選卡與換局清除舊按住旗標。

## 召喚球

每級1／2／3顆，尋敵半徑300／340／380。每球傷害=(攻×1.3+8)×本級1／1.35／1.7，再套持有者元素／等級與目標修正。每次180ms出擊、220ms回收，循環500／450／400ms；不同球錯開，排除不可破坏泥怪、核心與當前護盾。新增金色核心、曲線軌跡與命中紋。P1／P2同計算入口，CLIENT同步偏移與出擊姿勢。

## 刺客／槍手／分身

- 刺客八次穿梭，每段最多三次實際命中，總24刀；每刀大招總傷害/24，沒有敵人／目標死亡／護盾擋住不捏造傷害數字。穿梭距離上限620，候選範圍擴大至視窗附近、各軸最高650。收招220ms快速退155至周圍較空位置，退完800ms受傷保護，避免留在小王身上。
- 槍手大招發動當下找650內附近敵人；狙擊400ms蓄力完再鎖一次，從圖片真槍口朝敵人當前位置出彈。沒有可攻擊敵人時沿用面向，不額外鎖寶箱。跨局或持有者倒地／選卡時不發出舊狙擊。
- 影分身穩定本體70%可見度；輪廓只畫身體外側，35%低亮度，不再四個實心輪廓疊在本體後面造成假透明。

## 首頁與小怪

首頁劍士每520ms揮劍，左右移動，每四次沿用遊戲劍氣；獨立展示狀態，用finally恢復遊戲繪圖參照。繼續冒險移到練習模式下方，間距與分隔線分組，只在原冒險可續時顯示。圓形怪四格素材由內建image_gen編輯移除腳，保留綠色身體／眼睛／金色核心；沿用generate2dsprite去底／圖集整理，不程式畫怪物。圖集仍421格48組。
