# 生成美術實裝

將已核准 16 張卡牌預覽板接入遊戲，新增污泥王、燼角魔王、殘影斬與寶箱。原稿使用內建 image_gen；generate2dsprite 和 Pillow 僅去底、分格、對齊、縮放和打包。

新稿提示方向：
- 污泥王：捲層泥身、破銅冠、苔蘚岩手；八方向站立／出拳與六格淨化。
- 燼角魔王：黑曜鎧甲、象牙角、紫色臉、琥珀胸核、小蝠翼；八方向站立／施法與六格胸核崩解。
- 殘影斬：六格銀白刀線、紫色拖帶，向右繪製再旋轉至攻擊方向；無爆炸環與放射粒子。
- 寶箱：木板、銅金角帶、圓蓋與鎖扣；關閉、裂縫光、掀蓋、金幣四格。
- 結尾：同一城堡構圖，魔王核心消散後轉晨光，選定職業走入並轉正面。

來源和格數見 docs/generated-art-sources.json。原稿保留在角色預覽。圖集 assets/generated-art.png/json：1024×3712，228 格、24 組。

art-preview.html 使用遊戲共用繪圖入口，提供人物、武器、殘影斬、Boss、寶箱與結尾的手動展示。
電擊保留平滑雙線；眼睛沿用固定尺寸 drawSpriteWithEyes；坦克短手與盾牌縮放沿用。
伤害、碰撞、卡牌數值和 Boss 戰鬥階段保留；連弩僅加外觀旗標。
依 Dino 要求不跑遊戲操作測試；發布執行 npm run build。
