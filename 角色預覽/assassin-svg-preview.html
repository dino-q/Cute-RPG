刺客設計預覽

SVG 向量插圖 — 4 種設計方向
A. 暗影刺客
Shadow Assassin
深色尖角兜帽籠罩全身
兩道銳利金色貓瞳從暗處發光
身後拖曳暗影殘像 + 斗篷
B. 忍者刺客
Ninja Assassin
紫色長圍巾飄動 + 金屬護額
右眼銳利、左眼 X 型戰疤
刺髮從護額上方露出
C. 魅影刺客
Phantom Assassin
華麗半月面罩覆蓋下半臉
面罩有花紋和中央寶石
身體邊緣紫色幽焰飄動
D. 毒月刺客
Venom Crescent
左側月牙金屬眼罩 + 皮帶固定
右眼毒綠色貓瞳（配合背刺毒系）
匕首帶毒液滴落效果 + 旋轉刀環
← 實際遊戲大小（r=18）會是這麼小，所以設計重點是「輪廓辨識度」而非細節
SVG 向量風格：平滑曲線 + 漸層 + 濾鏡光暈 + CSS 動畫
全部保持紫色圓形身體 + 雙匕首，差異在頭飾/面部/特效
選定方向後會實作到 render.js（轉為 Canvas 繪製或預渲染為圖片快取）
